# ADR-018 — Exact-path local model transport

**Status:** Owner-approved on 2026-10-18 with canonical same-inode alias semantics. Ordinary transport and endpoint identity have independent public verification and matching packaged-source evidence. Live parent custody remains mandatory for every listener lifetime. Current-candidate ordinary qualification is blocked by preparation timing; retained-vault acceptance and release readiness remain incomplete.

## Decision

Add optional `unix_socket_path` to the shared `ModelSpec` and use HTTPX's UNIX-domain socket transport in the ordinary OpenAI-compatible adapter. TCP remains the default. The conversation configuration reads `VIVA_SPEAK_UNIX_SOCKET_PATH` with per-field fallback to `VIVA_MODEL_UNIX_SOCKET_PATH`. Extraction and conversation share the adapter's transport selection; this does not add that environment setting to every other model configuration loader.

UNIX configuration requires a canonical absolute path of at most 103 filesystem bytes, no empty, dot or parent components, no symlink components, the OpenAI-compatible adapter and an explicit logical `http://` base URL without credentials, query or fragment. Existing path components are inspected; an existing destination must be a socket. Validation runs before construction and dispatch. Each request uses a fresh HTTPX client, no transport retry, no redirect, `trust_env=False` and the existing timeout. There is no TCP fallback. Request bodies, tools, logical-URL paths and provider headers, response bodies and accounting retain their existing contracts.

`ModelSpec.endpoint_identity()` returns `model-endpoint-v1:` followed by a full SHA256 digest of a deterministic JSON tuple: identity version, transport kind, exact socket path or null, exact base URL or null, and adapter. Both measurement and runtime obtain it through the normal compiler factory. Distinct configured paths and URLs remain distinct; the digest avoids placing local paths in the profile's endpoint field. It identifies configuration, not an authenticated upstream provider or live socket inode.

Admission profiles advance from `semantic-request-admission-v8` to v9. Old profiles are rejected without conversion. Changing socket path, URL, adapter or transport requires fresh admission. Raw implementation provenance now includes `vivacore.models.spec` and `viva.speak` alongside the existing adapter, and the strict packaged source map grows from 60 to 62 modules. The same reviewed absolute path must survive qualification and runtime handoff; recreating the listener there requires a fresh live custody pin.

## Custody and accepted limits

The parent gateway must create and retain the listener under its own canonical 0700 directory with a 0600 socket. Before child launch, dispatch, delivery and cleanup, it must validate directory and socket type, current UID, mode, device/inode, and retained listener identity. It pins both objects for that listener lifetime, refuses replacements instead of adopting them, denies child mutation of the namespace and removes only the exact owned objects. A reusable admission profile cannot replace these checks. Protected namespace custody is necessary because inode inspection alone does not close a check/use race.

The owner accepts OS reachability through an alternate name resolving to the same permitted socket inode. Ordinary configuration still rejects aliases. Different live endpoints, including aliases switched to another inode, and the tested TCP destinations must remain denied. This contract does not promise denial of every textual alias, authenticate arbitrary same-UID processes, protect against an unrestricted external same-UID attacker, or establish comprehensive external-egress or race protection. The parent upstream route and resolved model remain separately pinned; the local transport does not widen that destination authority.

## Evidence and remaining gates

The first unpaid prototype stopped before launching children when listener inspection encountered an unsupported socket option, attributed to `SO_ACCEPTCONN` from source order without a retained traceback. That failure remains preserved. Corrected readiness validation preceded the bounded gate: three children and 82 checked outcomes, independently reviewed as passing with a finding. Different-endpoint and TCP denials, protected namespace controls and accepted same-inode alias reachability were exercised; a deliberately relaxed child made the negatives meaningful. Wrong-UID cases used synthetic metadata rather than privileged ownership changes. Earlier 3,000-exchange evidence was retained without repetition.

The independent reviewer required the production gateway to pin and recheck directory identity as well as the socket, including replacement and cleanup counterfactuals. Subsequent parent-bound native checks exercised the actual constructor with four positive and ten negative controls. Their passing result is scoped to those measured contexts; every new listener still requires fresh custody and exact source/artifact bindings. Synthetic outcomes establish machinery only and cannot mint a UDS admission profile.

Qualification041 remains **NOT_ADMITTED**: 117 measured passes and six unmeasured pre-gateway failures. Historical qualification043 admission does not admit changed source. Qualification046 was not admitted after a route failure, and qualification047 stopped before model dispatch; its separate narrow zero-request audit does not replace the missing full-capture audit. Qualification048 remains **NOT_STARTED**: the unpaid actual maximum exceeded the preparation deadline before transport, and the subsequent diagnostic prototype did not improve complete-checker timing. The existing authority for one conditional ordinary run remains unused; no automatic retry follows from these results. Successful current-candidate admission must precede retained-vault Q06, Q03 and the remaining financial-question campaign using the existing nineteen uploads. Formal acceptance remains **NOT READY**.

## Consequences

The model edge gains an ordinary local transport and exact destination binding while retaining deterministic arithmetic, capture-first accounting, append-only authority, encrypted sensitive captures and explicit upstream destination custody. The former base-URL-only endpoint key and 60-module provenance map no longer describe the candidate. v8 evidence cannot be relabeled as v9, and transport feasibility cannot repair or backfill the six unmeasured qualification cases.
